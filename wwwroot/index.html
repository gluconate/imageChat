    Your ideas, and where they go.

    Prompts and attached or reused images leave this machine and are sent to Microsoft Foundry for image generation. Chats and generated images are saved locally on the machine hosting the backend. Only the selected chat ID is kept in this browser’s local storage.

    “Use latest image” reuses the latest successfully generated image in this chat. A new attachment replaces that reference.
