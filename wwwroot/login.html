An administrator needs to set up Frame.

On the host machine, use the VS Code task ImageChat: Create administrator, or run powershell -NoProfile -File scripts/dev.ps1 create-admin on Windows or sh scripts/dev.sh create-admin on Linux/macOS. Enter credentials only in your own terminal. Restart the server afterward, then check again here.

No default credentials are created. Do not enter host credentials or API keys on this page.
